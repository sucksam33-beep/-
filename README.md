# Gilded Frontier · 황금과 무법의 시대

1870~1910년 캘리포니아를 배경으로 한 한국어 개척 경영 게임 프로토타입. 가로형 데스크톱 화면을 중심으로 만들었으며 작은 화면에도 대응합니다.

## 실행

Node.js 20 이상. 외부 런타임 패키지나 API 키가 필요하지 않습니다.

```sh
npm run dev
```

기본 포트는 3000이며 `PORT` 환경 변수로 변경할 수 있습니다. 검증은 `npm test`로 실행합니다.

## 플레이

- 지도를 드래그해 이동하고 휠 또는 +/− 버튼으로 확대합니다.
- 중앙 패밀리 구역에 살롱·금광·철도역·야영지를 건설합니다. 한 구역에 사업장 하나를 지을 수 있습니다.
- 인접 구역을 확보해 영토를 넓힙니다. 건설에는 자금이 필요합니다.
- 다음 턴으로 수익을 정산합니다. 한 턴은 한 계절이며 1910년 겨울 이후 결산합니다.
- 사업 장부에서 철도역을 바탕으로 석유 운송에 투자합니다.
- 세력 관계에서 다섯 갱단과 전투하거나 동맹을 맺고 조직원을 모집합니다.
- 세 턴마다 골드러시·이주·토지 분쟁·연방 조사 사건이 발생합니다. 선택에 따라 자금, 명성, 조직원, 수배도가 달라집니다.
- 현재 브라우저의 localStorage에 자동 저장합니다. 도움말에서 확인 후 새 게임을 시작할 수 있습니다.
- ♫ 버튼은 Web Audio로 합성한 독자적인 96 BPM 연주를 재생합니다. 특정 곡의 음원·멜로디·샘플을 포함하지 않습니다.

## 범위

참고 이미지의 서부 마을, 목조 살롱, 강변 조감도에서 분위기를 가져온 절차적 Canvas 2D 그래픽입니다. 실사 3D, 멀티플레이, 외부 음원, 역사 고증 시뮬레이션은 포함하지 않습니다. 허구의 인물과 사건으로 구성되며 원주민 공동체와의 분쟁에는 협상·철수·갈등 개입의 비용과 결과가 있습니다.

UI 폰트는 Google Fonts에서 선택적으로 불러오며 네트워크가 없어도 시스템 폰트와 모든 게임 기능이 동작합니다. 저장은 브라우저별로 독립적입니다.
